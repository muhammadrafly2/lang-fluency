# 🚀 Quick Start Guide - Nexora Multi-Language AI Coach

Get started with Nexora in 5 minutes!

## Step 1: Install & Run

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Step 2: Configure Settings ⚙️

Click the **Settings** icon (gear icon in top-right or center button on mobile)

### Required Settings:
1. **OpenRouter API Key** 🔑
   - Get your free key at [openrouter.ai/keys](https://openrouter.ai/keys)
   - Paste it in the "OpenRouter API Key" field

2. **Target Language** 🌍
   - Choose from:
     - 🇺🇸 English
     - 🇯🇵 Japanese
     - 🇰🇷 Korean
     - 🇪🇸 Spanish

3. **Proficiency Level** 📊
   - Beginner (A1-A2)
   - Intermediate (B1-B2)
   - Advanced (C1-C2)

### Optional Settings:
- **AI Voice**: Select preferred TTS voice
- **Speech Rate**: Adjust speaking speed (0.5x - 2x)
- **Voice Pitch**: Adjust voice pitch (0.5x - 2x)
- **Auto-play AI voice**: Toggle automatic speech
- **Show phonetic hints**: Toggle pronunciation guides

Click **Apply Settings** to save!

## Step 3: Start Practicing 🎯

### Option A: Voice Input (Recommended)
1. Click the **microphone orb** in the conversation view
2. Allow microphone permissions when prompted
3. Start speaking in your target language
4. The AI will respond and provide feedback

### Option B: Text Input
1. Type your message in the text box at the bottom
2. Press Enter or click the send button
3. Get instant AI response and feedback

## Step 4: Choose a Practice Mode 🎭

Select from 6 practice modes:

| Mode | Icon | Best For |
|------|------|----------|
| **Free Conversation** | 💬 | Natural, unstructured practice |
| **Role Play** | 🎭 | Real-world scenarios (shopping, doctor, etc.) |
| **Debate & Discuss** | 🏆 | Argumentation and persuasion |
| **Storytelling** | 📖 | Creative expression |
| **Job Interview** | 💼 | Professional preparation |
| **Pronunciation** | 🔤 | Accent and phonetic focus |

## Step 5: Understand Feedback 📝

After each message, you'll receive:

- ✅ **Great** - Things you did well
- ⚠️ **Suggestion** - Ways to sound more natural
- ❌ **Error** - Grammar or usage mistakes

Example feedback:
```
---
📝 Feedback

✅ Great: Excellent use of the past tense!
⚠️ Suggestion: Instead of "very good", try "excellent" for more impact
❌ Error: "I goed" → "I went" (irregular past tense)
```

## 🎨 Tutor Styles

Choose how you want to be coached:

- **😊 Friendly** - Warm and encouraging (default)
- **📚 Strict** - Direct corrections, high standards
- **🧠 Socratic** - Guided questions to self-discover mistakes

Change in Settings anytime!

## 🌍 Language-Specific Tips

### 🇯🇵 Japanese
- Practice different keigo levels (casual, polite, formal)
- Ask about kanji readings when unsure
- Focus on particle usage (は、が、を、に、で)

### 🇰🇷 Korean
- Practice both 존댓말 (formal) and 반말 (informal)
- Ask about honorific verb endings
- Work on pronunciation of double consonants

### 🇪🇸 Spanish
- Practice both tú and usted forms
- Focus on ser vs. estar
- Ask about subjunctive mood usage

### 🇺🇸 English
- Practice idioms and expressions
- Work on formal vs. informal register
- Focus on natural conversation flow

## 🔧 Troubleshooting

### Microphone Not Working
- Check browser permissions (Chrome/Edge recommended)
- Ensure microphone is not used by another app
- Try refreshing the page

### AI Not Responding
- Verify API key is correct
- Check internet connection
- Look for error messages in toast notifications

### Voice Not Playing
- Check "Auto-play AI voice" is enabled in Settings
- Verify browser supports TTS
- Try selecting a different voice

### Wrong Language Recognition
- Verify correct language selected in Settings
- Speak clearly and at moderate pace
- Check browser language support
