# 🌟 Nexora Features Overview

## 🌍 Multi-Language Support (NEW!)

### Supported Languages

| Language | Flag | Code | Features |
|----------|------|------|----------|
| **English** | 🇺🇸 | en-US | Natural expressions, idioms, business English |
| **Japanese** | 🇯🇵 | ja-JP | Keigo (敬語), kanji/hiragana/katakana, cultural nuances |
| **Korean** | 🇰🇷 | ko-KR | Honorifics (존댓말/반말), Hangul, formality levels |
| **Spanish** | 🇪🇸 | es-ES | Tú/Usted, subjunctive, regional variations |

### How It Works
- Select your target language in Settings
- AI responds in that language
- Speech recognition automatically adjusts
- Get feedback on grammar, pronunciation, and cultural usage
- Language indicator always visible in header

## 🎯 Practice Modes

### 1. 💬 Free Conversation
- **Best for**: Natural, unstructured practice
- **Focus**: Everyday topics, casual chat
- **Example**: "Tell me about your weekend"

### 2. 🎭 Role Play
- **Best for**: Real-world scenarios
- **Focus**: Practical situations
- **Examples**: 
  - Shopping at a store
  - Visiting a doctor
  - Ordering at a restaurant
  - Hotel check-in

### 3. 🏆 Debate & Discuss
- **Best for**: Argumentation skills
- **Focus**: Persuasion, critical thinking
- **Example**: "Should remote work be mandatory?"

### 4. 📖 Storytelling
- **Best for**: Creative expression
- **Focus**: Narrative skills, descriptive language
- **Example**: Build a story together, taking turns

### 5. 💼 Job Interview
- **Best for**: Professional preparation
- **Focus**: Business language, formal speech
- **Examples**:
  - "Tell me about yourself"
  - "What are your strengths?"
  - Technical interviews

### 6. 🔤 Pronunciation
- **Best for**: Accent improvement
- **Focus**: Phonetic accuracy, intonation
- **Example**: Practice difficult sounds and words

## 📝 Feedback System

### Real-Time Corrections

Every message receives structured feedback:

#### ✅ Great (Positive)
- Highlights what you did well
- Reinforces correct usage
- Builds confidence

#### ⚠️ Suggestion (Improvement)
- More natural alternatives
- Idiomatic expressions
- Style improvements

#### ❌ Error (Correction)
- Grammar mistakes
- Wrong word usage
- Incorrect conjugations
- Shows correct form

### Feedback Format
```
[Your conversational response in target language]

---
📝 Feedback

✅ Great: [positive points]
⚠️ Suggestion: [improvements]
❌ Error: [corrections with explanations]
```

## 🔒 Privacy & Security

### Data Handling
- API key stored locally (browser localStorage)
- No server-side storage of credentials
- Conversations sent to OpenRouter for processing
- No conversation history stored on servers

### Browser Permissions
- Microphone access (for voice input)
- Local storage (for settings)
- No tracking or analytics

## 📊 Technical Stack

### Frontend
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State**: React Hooks

### AI & Speech
- **AI Model**: Nvidia Nemotron (via OpenRouter)
- **Speech Recognition**: Web Speech API
- **Text-to-Speech**: Web Speech Synthesis API

### Deployment
- **Platform**: Vercel (recommended)
- **Build**: Turbopack
- **Environment**: Node.js 18+
